## winget

先打开 PowerShell（管理员），执行：

```bash
winget install -e --id IcarusVerilog.IcarusVerilog

winget install -e --id gtkwave.gtkwave
```


装完验证：

```bash
iverilog -V

vvp -V

gtkwave --version
```
