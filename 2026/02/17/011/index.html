Mindset

  • Future
    • (2026.1)【硅基天启：灭世之技术推演 [ChinaSys’25 Winter]】 【演讲者蒋炎岩的后续补充】
      • 三个研究问题和通向解决的技术途径：
        • 消灭教师的 “Everything is a state machine” → 状态迁移/转换上课；
        • 消灭码农的 “Spec-oriented programming” → 写混合语言手册生成项目；
        • 消灭全人类的 “Small explanation hypothesis” → 枚举解释生成结果
  • Vide Coding
    • easy-vibe
      • 一个把 AI 编程从入门到工程化落地打通的中文开源学习体系
    • (2026.1) 现状
    • (2025.8) Vibe-coding is not the same as AI-Assisted engineering.
      • “vibe coding” 和 “AI-assisted engineering（AI辅助工程）不是一回事，别混为一谈。
      • (2025.8) good example of AI-Assisted engineering (not vibe coding actullay)
    • 想用“凭感觉编程（Vibe coding）”来打造一款真正的产品，是行不通的。但用它来做原型，那简直太棒了。
    • (2025.9) Vibe Coding Is Creating Braindead Coders
      • 过度“vibe coding”会让程序员变弱，像在“赌代码结果”而不是在做工程思考
    • AI 杀不死软件工程，反而使软件工程的那些古老规则再次伟大。
      • 在 AI 辅助编程的时代，自动化软件测试正变得越来越重要。
