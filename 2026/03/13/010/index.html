自建影视聚合平台

编辑原文
2026-03-13 技术文章 1.9k 字
claude

影视平台地址

https://xwwcyber.github.io/cinema/

因为没有买域名，所以暂时需要VPN才可以访问

项目概述

这是一个功能完整的影视资源聚合平台，支持多数据源切换、深色/浅色主题、收藏和历史记录等功能。用户可以在一个统一的界面中浏览、搜索和播放来自多个资源站的影视内容。

核心特性：

  • 🎬 多数据源聚合（7个默认资源源）
  • 🔍 全文搜索功能
  • 🌙 深色/浅色主题切换
  • ❤️ 收藏功能
  • 📜 观看历史记录
  • 🎯 智能播放源筛选
  • 📱 响应式设计

技术架构

前端技术栈

  • HTML5 - 语义化标记
  • CSS3 - 响应式设计和主题系统
  • Vanilla JavaScript - 无框架依赖
  • LocalStorage - 本地数据持久化

后端支持

  • Express.js - 代理服务器
  • CORS 代理 - 跨域请求处理
  • Cloudflare Workers - 云端代理服务

核心模块

src/
├── js/
│   ├── api.js      # API 请求和数据处理
│   ├── ui.js       # UI 交互和渲染
│   ├── store.js    # 数据存储管理
│   └── config.js   # 配置和常量
├── css/
│   └── style.css   # 样式表
└── pages/
    ├── index.html  # 首页
    ├── detail.html # 详情页
    └── player.html # 播放页

核心功能详解

1. 数据源管理

平台支持多个影视资源站，用户可以灵活切换：

默认数据源：

  • 默认源 (api.apibdzy.com)
  • 闪电资源 (sdzyapi.com)
  • 量子资源 (cj.lziapi.com)
  • 百度资源 (bdzy1.com)
  • 极速资源 (jszyapi.com)
  • 新浪资源 (api.xinlangapi.com)
  • 红牛资源 (hongniuzy2.com)

功能特性：

  • 添加自定义数据源
  • 编辑现有数据源
  • 删除不需要的数据源
  • 实时切换数据源
  • 数据源配置本地保存

2. 智能播放源筛选

资源站通常提供多个播放源，系统自动筛选最优方案：

筛选逻辑：

// 多播放源格式示例
vod_play_from: "liangzi$$$lzm3u8"
vod_play_url: "第01集$url1#第02集$url2$$$第01集$url3#第02集$url4"

// 自动筛选 m3u8 格式
// 优先使用支持 HLS 的播放源
// 支持播放源切换

支持的播放器：

  • HTML5 Video
  • HLS.js (m3u8 格式)
  • 多播放源切换

3. 异步海报加载

优化首屏加载速度：

加载流程：

  1. 列表页先显示影视标题
  2. 后台异步加载详情信息
  3. 获取海报图片并缓存
  4. 动态更新页面显示

缓存策略：

  • 海报缓存（最多 200 条）
  • 详情缓存（5 分钟过期）
  • 自动清理过期数据

4. 跨域处理

使用多个 CORS 代理服务解决跨域问题：

代理配置：

// 本地开发
http://localhost:3001/proxy

// Vercel 部署
/api/proxy

// Cloudflare Workers
https://cinema-proxy.xwwcyber.workers.dev/proxy

特性：

  • 自动代理轮换
  • 请求超时处理（30秒）
  • Cloudflare 限速自动重试
  • 错误恢复机制

5. 主题系统

支持深色和浅色主题切换：

实现方式：

  • CSS 变量主题系统
  • 主题配置本地保存
  • 实时切换无需刷新
  • 系统主题自适应

6. 收藏和历史记录

用户个性化功能：

收藏功能：

  • 添加/移除收藏
  • 收藏列表管理
  • 批量删除
  • 本地持久化

历史记录：

  • 自动记录观看历史
  • 显示最后观看时间
  • 单条删除
  • 批量清空

?ac=detail&ids=ID 获取影视详情 ids(视频ID)

  • 数据源选择器

交互特性：

  • 基本信息（名称、分类、导演、演员）

播放功能：

常见问题

Q: 为什么某些资源站无法访问？

A: 资源站可能存在以下问题：

  • 服务器宕机或维护
  • IP 被限制
  • 需要代理访问
  • 接口格式变更

解决方案：

  • 切换其他数据源
  • 添加自定义数据源
  • 检查网络连接
  • 查看浏览器控制台错误信息

Q: 播放器无法播放视频？

A: 常见原因：

  • 播放源不支持 m3u8 格式
  • 视频链接已失效
  • 浏览器不支持 HLS
  • 跨域限制

解决方案：

  • 尝试切换播放源
  • 更新浏览器版本
  • 检查代理服务是否正常
  • 查看浏览器控制台错误

Q: 如何添加自定义数据源？

A:

  1. 点击页面右上角”数据源”按钮
  2. 选择”添加数据源”
  3. 输入数据源名称和 API 地址
  4. 点击保存

数据源 URL 格式：

https://api.example.com/api.php/provide/vod/

Q: 收藏和历史记录存储在哪里？

A: 所有数据存储在浏览器 LocalStorage 中：

  • 不会上传到服务器
  • 清除浏览器数据会丢失
  • 不同浏览器数据独立
  • 可手动导出/导入
