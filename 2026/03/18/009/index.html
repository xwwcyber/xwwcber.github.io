    关于claude code的使用体验

    编辑原文
    2026-03-18 AI 1.2k 字
    claude

    安装

    npm install -g @anthropic-ai/claude-code

    配置

    安装好claude code之后，需要你自己去配API，下面那个是我使用claude code的中转站

    可以使用最新的Opus 4.6

    https://api123.icu/console

    启动

    # 在项目根目录启动
    cd your-project
    claude

    就这么简单。Claude Code 会自动识别你的项目结构，读取 CLAUDE.md 配置文件（如果有的话），然后等待你的指令。

    claude code与传统IDE的区别

    1.交互形态的不同

    传统的 IDE 主要是由图形界面 (GUI) 主导的，开发者在编写代码时高度依赖鼠标的点击、菜单的导航以及手动敲击键盘。而 Claude Code 则是以命令行终端 (CLI) 为主导，你主要通过自然语言与它进行对话来输入指令，交流方式更加直接。

    2.上下文理解的深度

    传统 IDE 的理解能力通常是局部的、基于规则的，它能看懂当前文件的语法和变量引用关系，方便你做局部的代码重构或跳转追踪。但 Claude Code 具备全局和基于语义的理解能力，它可以通读你整个代码库的内容，从而理解不同业务模块之间复杂的逻辑关联。

    3.执行能力

    传统 IDE 提供编译和调试按钮，但需要你手动配置和触发。但 Claude Code可以自主搜索文件、读写代码、甚至帮你运行终端命令（如编译、跑测试）。

    claude code的优势

    1.具备长时间自主工作的能力 (Long-running Agentic Loop)

    传统的 AI 辅助往往是“一问一答”的单次交互，但 Claude Code 能够进行长时间、多步骤的自主工作循环。当你抛给它一个宏大且繁琐的任务，它会自己拆解任务。你可以把一个费时的重构任务丢给它，让它在终端里长时间默默“搬砖”，直到最终达成目标。

    2.装备了实用的“技能库” (Skills)

    Claude Code 内部集成了一套动作指令（Skills），让它可以像人类程序员一样工作。这些技能包括：读取和编辑指定文件、浏览目录结构、全局搜索代码关键词（grep）、执行终端 Shell 命令，能帮你打包提交 Git，美化前端UI界面。

    claude code 的实用skills

    • find-skills
      • 你只需要描述一下你需要什么功能的skills，这个技能会帮你搜索claude code的相关skills，类似于我们手机的应用商店
    • skill-creator
      • 这个是可以创造自己想要的skills，跟着他的步骤一步一步走，你也可以直接和claude code说，让他帮你创造
    • frontend-design
      • 这个是前端美化的相关skills
    • git-commit
      • 自动生成 Conventional Commits 格式的提交，可以帮你推送到github上
    • review-pr
      • 审查 PR 的代码质量、安全性和测试覆盖率，你给他你的pr网址，他会帮你分析
    • simplify
      • 审查修改过的代码，检查复用性、质量和效率问题并修复
    • ralph
      • 将 PRD 文档转换为 Ralph 自主代理系统的 JSON 格式，然后通过Loop，就可以长时间工作了

    claude code如何长时间工作

    首先需要安装上面那个ralph

    在claude code中执行下下面两行命令

    /plugin marketplace add snarktank/ralph
    /plugin install ralph-skills@ralph-marketplace

    执行完成说明你已安装两个技能

    • /prd：生成需求文档
    • /ralph：把 PRD 转成 prd.json

    接下来按下面标准流程走。

    标准流程（Claude Code + Ralph）

    第 1 步：进入项目根目录

    cd your-project         #进入你的项目目录里
    mkdir -p scripts/ralph  #创建这个文件夹，这个是放ralph循环脚本的

    第 2 步：用 /prd 生成 PRD

    让 Claude 生成功能需求文档prd.md，放在项目根目录下就行

    第 3 步：用 /ralph 转成 prd.json

    把刚才 PRD 转成 Ralph 可执行的 JSON 任务清单。

    这一步完成后，你的项目根目录应该有 prd.json。

    第 4 步：把 ralph.sh 放进项目（关键）

    Marketplace 安装的是“技能”，不会自动把循环脚本塞进你的项目。

    你需要先把这个仓库拉下来，放在哪里都行

    git clone  https://github.com/snarktank/ralph.git

    把ralph.sh和CLAUDE.md移到你的项目地址/scripts/ralph文件夹里面

    # 复制这个循环脚本
    cp /这个仓库的地址/ralph/ralph.sh scripts/ralph/ralph.sh

    # 复制您选择的AI工具的提示模板
    cp /这个仓库的地址/ralph/CLAUDE.md scripts/ralph/CLAUDE.md    # For Claude Code

    建议目录结构：

    your-project/
      scripts/
        ralph/
          ralph.sh
          CLAUDE.md
      prd.json
      prd.md

    第 5 步：授予脚本权限并执行

    chmod +x scripts/ralph/ralph.sh
    ./scripts/ralph/ralph.sh --tool claude 10

    这里的 10 是最大迭代次数。
